# A501 适配实例

通用检查器不认识本项目 UART，也不导入 NumPy。本适配例负责从既有 A501 工程读取并严格解析原始 TX/RX，调用已冻结的协议与算法核验，再导出通用检查器所需的整数结果列表和计时记录。

从工程根目录运行：

```powershell
python -B -X utf8 skill/scripts/project_adapter.py .
```

依赖与主工程相同，见根目录 requirements.txt。这一步会重放 1704 个独立应用输入与同一四报文输入的 30 次校验模式计时；不会打开串口，不写入原数据，不重新计算板卡测量值。运行模式未执行的 CPU 数据不伪造为新的 CPU 试验。

输入指纹覆盖 samples、固定模板、7/10 阈值、容量 4 和 64 点排除距离。输出严格按硬件的选择顺序保留 `(position, score, energy)`，不含仅用于展示的浮点相关系数。原始 UART 先检查响应类型、序号、CRC 和 BUILD_ID，因此不能只在标准文件中填一个版本字符串就视为通过。

本例依赖项目格式，故不宣称直接可用于其他题目；其他团队仅需按 schema.md 写自己的导出适配器，即可原样使用 audit.py。独立点积/FIR 夹具不导入任何 Z100 模块，用于检验这种解耦。

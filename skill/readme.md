# FPGA 软硬件结果核验与可复现实验

这是面向整数 FPGA 加速项目的可复用技能包。它把本项目的四类工程经验提炼成与板卡、UART 协议和检测算法无关的 Python 工具：同输入精确结果比较、版本对应、文件校验、同任务计时检查。Python 3.10 及以上即可运行，仅用标准库。无须 Z100、Vivado、串口或本项目主机程序。

## 直接试用

在 skill 目录中执行：

```powershell
python -B scripts/run_examples.py
```

应返回整体 `status: PASS`。示例含两个不同任务：有符号点积与三抽头 FIR 的 valid 输出；FIR 约定 y[n]=x[n]-x[n-1]+2x[n-2]，预期结果分别为 -16 和 [3,5]，可手工核算。串口记录和时间数据是独立构造的测试夹具，不是新增板测。错误结果、漏项、重复编号、旧版本、不同输入、浮点/布尔冒充整数、文件变动、路径越界和不公平计时必须被拒绝。

## 在其他题目中使用

1. 先写清整数输入范围、结果位宽、舍入/饱和规则、同分处理、状态与超时。保留独立黄金参考，不从被测 RTL 输出反向生成答案。
2. 在原串口、AXI、PCIe 或文件工具中完成协议解析与 CRC/序号检查，导出下述标准 JSONL。工具不直接操作硬件，也不代替协议解析器。
3. 固定输入、源码/产物清单和版本编号，分别核对结果、文件和计时。错误时保留原始数据；不要更新黄金答案或旧哈希来“通过”。
4. 再运行实际仿真和板测，分别标识软件参考、RTL、实现后、下载、实板计算与恢复。文件回放通过不等于新上板成功。

```powershell
python -B scripts/audit.py compare expected.jsonl observed.jsonl --build-id my_v1
python -B scripts/audit.py files project_root artifact_manifest.json
python -B scripts/audit.py timing timing.json
```

返回 0 表示本项通过，返回 2 表示拒绝，并输出失败原因；程序不写入输入文件。具体字段和适配例子见 [schema.md](schema.md)。本项目的可追溯适配见 [project_adapter.md](project_adapter.md)。

## 适用范围与失效条件

| 项目 | 适用 | 不能据此声称 |
|---|---|---|
| 精确整数比较 | 点积、整数 FIR、矩阵运算、整数图像/信号处理 | 不适用于未定义容差的浮点、近似算法；不自动理解字节序/符号位 |
| 输入与版本对应 | 独立参考和实测拥有相同输入哈希、明确 build_id | 版本字符串可被误填，须结合固件响应、产物清单和解析器检查 |
| 文件 SHA256 | 可信清单下的文件损坏、遗漏、混版检查 | 不构成作者身份认证或防恶意篡改签名；允许清单外额外文件 |
| 同任务计时 | 同频率、同版本、同输入、完整板内任务且各模式重复次数相等 | 不验证实际计时器插桩是否正确；不把核心周期或串口时间混算 |

检查器要求结果只含整数、null、数组或以字符串为键的对象。需要浮点时应另定义绝对/相对误差、NaN 与溢出行为，不能直接放宽比较条件。对 DMA 缓存一致性、跨时钟域或真实采样质量，本包只提供证据流程，不提供驱动或功能保证。

## 已验证的效果

[validation.json](validation.json) 保存独立夹具与故障注入的实际运行结果；[project_validation.json](project_validation.json) 保存对冻结 A501 应用证据的适配检查。前者证明检查器对两类任务可复用并能拒绝已列故障，后者证明接口能承载本项目真实结果。其他板卡需要单独编写协议适配器并验证。

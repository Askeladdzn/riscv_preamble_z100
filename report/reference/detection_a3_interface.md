# 兼容命令五字段

版本 0000A301，在 [A2 接口](detection_interface.md) 上新增公平对比命令 5。既有 RTL、MMIO、命令 1/2/3/4 保持；A2 的源文件与记录保留，不能把 A301 当作 A201。

## 命令 5：逐窗口调用原 DOT

请求与 DETECT 相同：uint16 N、uint16 flags=0、int16 samples[N]。N=64–1024、样本 -2048..2047。响应 0x85，112 字节，小端 28 个 uint32：

| 字索引 | 含义 |
|---|---|
| 0–2 | N、窗口数、软件/硬件不一致窗口数 |
| 3 | 固定 1，表示本次每窗口搬模板；不是扫描器首载标志 |
| 4–13 | 软件与硬件的 detected、position、candidate、S、E |
| 14–16 | 软件完整周期、旧流程完整调用周期、所有 DOT 核心周期之和 |
| 17–19 | 0xffffffff，未提供分段周期，不能画成有效数值 |
| 20–24 | 软件/硬件 CRC、命令 3+5 合计完成数、DOT 状态、BUILD_ID |
| 25–27 | 本请求样本写 64×(N-63)、模板写 64×(N-63)、DOT 启动 N-63 次 |

TRACE 读取最近成功命令 3 或 5 保存的 S/E。INFO 的 DOT 完成数只计命令 2；扫描器 START 累计只计命令 3。未检测位置为 0xffffffff；S 解释为 int32。固件检查 DOT 高字的符号扩展。

旧流程能量由 CPU 计算，新扫描器计算 S/E；最终判决相同，计时都覆盖必要工作。旧计数按循环长度推导，集成仿真从总线实际计数交叉检查。


本文件描述保留的旧流程命令字段，最终入口见 readme.md。

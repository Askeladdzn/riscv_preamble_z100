# 基础系统与点积寄存器

地址、数据均为 32 位，小端；主时钟 50 MHz。最小系统与加速器 MMIO 集成已通过阶段 4 实板三方验证，最新固件为 00004001。

## 最小系统

| 地址 | 名称 | 行为 |
|---|---|---|
| 0x00000000–0x0000ffff | RAM | 64 KiB，同步 BRAM；支持 byte/halfword/word 写使能；固件随 bitstream 初始化 |
| 0x10000000 | UART_STATUS | 只读；bit0 接收非空，bit1 发送空闲，bit2 接收溢出，bit3 帧错误 |
| 0x10000004 | UART_RX | 读出并弹出一个字节；空时返回 0xffffffff；写入无效果 |
| 0x10000008 | UART_TX | 写最低字节发送；忙时推迟总线响应，避免丢字节 |
| 0x1000000c | UART_CLEAR | 写 bit0=1 清除溢出和帧错误；同周期新错误优先保留 |
| 0x10000010 | CYCLE_LO | 复位后累计时钟数的低 32 位 |
| 0x10000014 | CYCLE_HI | 同一计数器的高 32 位；完整读取采用 high-low-high 重试 |
| 0x10000018 | CLOCK_HZ | 返回 50000000 |
| 0x1000001c | SYSTEM_ID | 返回 0x52563031，即 RV01 |

CPU 请求仅在 mem_valid=1 且前一拍 mem_ready=0 时执行；响应期间不会重复弹出 UART 数据或重复发送。32 字节接收 FIFO 支持同周期入队/出队。UART 错误保持至明确清除或复位。

未映射访问返回 0，并锁存总线错误；从 MMIO 取指也锁存错误。LED1 指示 CPU trap、总线错误或 UART 错误的逻辑或；LED0 是时钟心跳。LED 电平与实际亮灭还受板载驱动极性影响。

阶段 2 的 bringup 固件保留 ASCII 自检命令：S 自检、E 异或变换。阶段 4 的 vector 固件 00004001 使用 [二进制帧](uart_protocol.md)，包含长度、序号、CRC 和超时恢复，不接受这些 ASCII 命令。

## 加速器接口（阶段 4 已集成并实测）

CPU 将 0x20000000–0x20003fff 译码到 dot_accel，模块使用低 14 位相对地址。每个已接受事务只产生一拍 access；完整 CPU 仿真通过事务计数确认没有重复写入。rst 使用既有同步复位。

| 地址 | 名称 | 约定 |
|---|---|---|
| 0x20000000 | COMMAND | 全字写 1 启动；全字写 2 清 DONE/ERROR；其他值为命令错误 |
| 0x20000004 | STATUS | bit0 BUSY，bit1 DONE，bit2 ERROR |
| 0x20000008 | LENGTH | 空闲时全字写入长度；START 时检验 1–1024 |
| 0x2000000c | ERROR_CODE | 0 无错误；1 长度非法；2 BUSY 时修改；3 未映射地址写入；4 非对齐写、写入格式/命令非法 |
| 0x20000010 | RESULT_LO | 有符号 64 位结果的低 32 位 |
| 0x20000014 | RESULT_HI | 同一结果的高 32 位；完成后保持，直至下一次有效 START 或复位 |
| 0x20000018 | CORE_CYCLES | 有效 START 到 DONE 的时钟周期差；不含输入写入和 CPU 读取 |
| 0x2000001c | ACCEL_ID | 0x444f5431，即 DOT1 |
| 0x20001000+4*i | A[i] | i=0..1023；写低 16 位，允许低两个字节的 byte enable；只写，读返回 0 |
| 0x20002000+4*i | B[i] | 同上 |

BUSY 时 START、CLEAR、LENGTH 或输入写入都被忽略并记录错误，不破坏正在运行的计算。非法 START 不清除先前结果。新一次有效 START 清 DONE/ERROR、结果和周期计数；复位终止当前任务并清状态，BRAM 数据无需复位。读取不改变状态。

已实现同步读数、16×16 乘法、64 位累加的单路流水线。阶段 3 的 1017 组 RTL/综合后功能仿真、阶段 4 的 67 组实板计算均验证核心周期为 N+2；它不包含搬运及调用开销。只写或未定义地址读返回 0，不改变状态。BUSY 时任何写入均按错误码 2 拒绝。固件只把 DONE=1、BUSY=0、ERROR=0 的结果当作成功。
